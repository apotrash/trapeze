Trapèze

Transcrivez et résumez vos vidéos, sur votre Mac. Vos fichiers, vos transcriptions et vos résumés restent chez vous.

Télécharger pour Mac

Apple Silicon · macOS

Installation

  1. Ouvrez le fichier téléchargé, puis glissez Trapèze dans votre dossier Applications.
  2. Lancez l’application. Aucun avertissement de sécurité : elle est signée et certifiée par Apple.
  3. Saisissez votre code d’activation, reçu au format XXXX-XXXX-XXXX-XXXX.

Ce qu’il vous faut

Un compte Claude ou ChatGPT

Trapèze n’inclut aucun abonnement d’intelligence artificielle : il utilise le vôtre, avec l’outil officiel du fournisseur. Le guide affiché au premier lancement vous accompagne pour le connecter.

Sans fournisseur configuré, la transcription fonctionne. Seuls les résumés en ont besoin.

Vos données

Ce qui reste sur votre Mac

  • Vos fichiers vidéo d’origine, jamais modifiés
  • Vos transcriptions, vos résumés et leurs versions successives
  • Vos dossiers, étiquettes et favoris

Ce qui en sort, et seulement si vous le demandez

Quand vous demandez un résumé, la transcription est envoyée au fournisseur que vous avez choisi, avec votre propre compte, et traitée selon ses conditions.

L’activation transmet une seule fois votre code et une empreinte anonyme de votre machine — un calcul à sens unique, jamais l’identifiant de votre matériel.

Configuration requise : Mac à puce Apple Silicon. Toutes les versions
